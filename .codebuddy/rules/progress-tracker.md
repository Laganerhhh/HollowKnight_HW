# 记忆同步规则

## 强制性行为

### 1. 每次对话开始时（优先级最高）
- **必须**先检查 `DEV_PROGRESS.md` 是否存在
- 若存在，读取并简要总结当前项目状态
- 若不存在，立即创建并告知用户

### 2. 每次代码修改后（包括但不限于）
- 新增功能
- 修复Bug
- 重构代码
- 修改配置

**必须**调用 `progress-tracker` skill 记录修改摘要

### 3. 记录格式规范
- 每条记录不超过 3 句话
- 必须包含修改的文件路径
- 必须标注是否涉及数据库变更或API变更

### 4. 异常处理
- 若用户说"不用记录"或"跳过"，仍记录一条简短标记 `[用户要求跳过记录]`
- 若修改涉及多个文件，合并为一条记录
```
